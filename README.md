# Zhitong Cui Personal Website

This is a static personal website generated from `cv.md`.

## Local Preview

Open `index.html` directly in a browser.

## GitHub Pages

1. Create a GitHub repository.
2. Push `index.html`, `styles.css`, `avatar.jpg`, `cv.md`, and this `README.md`.
3. In the repository settings, enable GitHub Pages from the main branch root.
